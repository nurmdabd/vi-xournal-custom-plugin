# Key bindings

## tool mode

* Annotate PDF: `o`
* Color mode: `c`
* Delete: `x`
* Eraser: `e`
* File mode: `f`
* Hand: `space`
* Highlighter: `h`
* Linestyle mode: `l`, `q`
* Navigation mode: `n`
* NewAfter: `a`
* Page mode: `b`, `p`
* Pen: `w`
* Redo: `y`
* Resize mode: `r`
* Selection: `k`
* Shape mode: `s`
* Sticky color mode: `<Shift>c`
* Sticky file mode: `<Shift>f`
* Sticky linestyle mode: `<Shift>l`
* Sticky navigation mode: `<Shift>n`
* Sticky page mode: `<Shift>b`, `<Shift>p`
* Sticky shape mode: `<Shift>s`
* Sticky visual mode: `<Shift>v`
* Tex: `i`
* Text: `<Shift>t`, `<Shift>i`
* Tool mode: `t`
* Undo: `d`, `u`, `z`
* Visual mode: `v`
* Zoom in: `greater`, `<Shift>greater`, `plus`, `<Shift>plus`
* Zoom out: `minus`, `less`

## color mode

* Black: `x`
* Blue: `b`
* Cyan: `c`
* Green: `g`
* Orange: `o`
* Pink: `q`
* Purple: `p`, `a`
* Red: `r`
* Tool mode: `t`
* White: `w`
* Yellow: `y`

## shape mode

* Arrow: `a`
* Ellipse: `e`
* Fill: `f`
* Rectangle: `r`, `c`
* Ruler: `s`
* Spline: `b`
* Tool mode: `t`

## linestyle mode

* DashDotted: `a`, `h`
* Dashed: `d`
* Dotted: `o`
* Plain: `l`, `p`
* Tool mode: `t`

## page mode

* Delete Layer: `x`
* DeletePage: `d`
* Dotted background: `v`
* Graph background: `g`
* Isometric dotted background: `b`
* Isometric graph background: `r`
* Move Down: `s`
* Move Up: `w`
* New After: `a`
* New Before: `<Shift>a`
* NewLayer: `y`
* Plain background: `n`
* Ruled background: `f`
* Tool mode: `t`
* copyPage: `c`

## file mode

* Annotate PDF: `a`, `o`
* Export as PDF: `e`
* Open file: `f`
* Save file: `s`, `w`
* Save file as ...: `<Shift>s`, `<Shift>w`
* Tool mode: `t`

## navigation mode

* Go back to last visited page: `a`
* Go to bottom: `b`
* Go to first page: `g`
* Go to last page: `<Shift>g`, `e`
* Go to top: `<Shift>b`
* Layer Down: `x`
* Layer up: `y`
* Scroll page down: `s`
* Scroll page up: `w`
* Tool mode: `t`

## visual mode

* Select Object: `o`
* Select Rectangle: `v`, `r`
* Select Region: `e`
* Tool mode: `t`

## resize mode

* Fine: `f`
* Medium: `m`, `r`
* Thick: `h`
* Tool mode: `t`
* Very Fine: `e`
* Very thick: `v`
